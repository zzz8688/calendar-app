智能日历（Android）                                                                                                                                                                                                                                                            
项目内容：这是一款遵循RFC 5545 (iCalendar)国际标准的Android日历应用，完成核心的数据库结构设计、日程管理业务逻辑实现，以及对iCalendar数据格式的解析与处理，以支持事件的导入导出功能。
